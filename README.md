# OpenCC - Open C Compiler

OpenCC is a fork of [chibicc](https://github.com/rui314/chibicc), but with a catch. OpenCC aims to support C23 and its rewritten from C11 to C++20.

**NOTE:** OpenCC is under development, so most of features can not work.

## Features

✓ - done
? - InDev/Partial
✗ - not implemented 

- [✓] -std= flag support
- [✗] arm64 codegen support
- [?] termux support
- [✗] support of inline functions
- [✗] better error and warning handling
- [✗] contexpr, auto keywords
- [?] bool, true, false as keywords
- [✗] basic optimizations
- [✗] advanced optimizations
